# UrbanRoute Fleet

UrbanRoute Fleet is an enterprise-grade B2B web application designed to optimize electric vehicle (EV) fleet operations. It serves as a unified charging and route planning engine that helps fleet managers and dispatchers eliminate mid-shift range anxiety, reduce missed charging sessions, and seamlessly calculate energy requirements based on payload and distance.

## Key Features

* **Role-Based Workflows:** Tailored UI experiences for Fleet Managers (data management, overviews) and Dispatchers (rapid route calculation).
* **Live Route Engine:** Calculates estimated energy needed, total distance, and projected arrival battery levels based on stops and payload.
* **Command Center Dashboard:** High-level KPIs tracking active routes, total vehicles, low battery warnings, and charging slot conflicts.
* **Progressive Disclosure UI:** A clean, forgiving interface that prioritizes "glanceability" to keep dispatchers moving fast.
* **Mobile-First & Responsive:** Built to work just as smoothly on a dispatcher's mobile device in the field as it does on a dual-monitor desktop setup.

## Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **UI Framework:** Bootstrap 5
* **Icons:** FontAwesome
* **Architecture:** Component-driven design (using pure JS/DOM manipulation) mapped to a JSON schema for easy backend integration.
